# ☁️ CloudPulse: Revolutionizing AWS Monitoring & Auto-Remediation with Terraform

Welcome to CloudPulse, a cutting-edge infrastructure-as-code (IaC) project that leverages the power of Terraform on AWS to deliver unparalleled observability, alerting, and auto-remediation in a cloud-native environment. Whether you're a cloud enthusiast or a seasoned DevOps professional, CloudPulse offers a comprehensive toolkit to streamline your cloud operations.

---

## 📊 Project Overview

CloudPulse is designed to showcase a robust and scalable approach to cloud infrastructure management. Here's what you can expect:

- EC2 Provisioning: Seamlessly provision and manage EC2 instances using Terraform, AWS EC2, and IAM.
- Monitoring Agent: Deploy the CloudWatch Agent on Amazon Linux 2 to gain real-time insights into your infrastructure's performance.
- Custom CloudWatch Alarms: Set up intelligent alarms to monitor CPU usage and other critical metrics, ensuring you're always in the loop.
- Email Notifications: Stay informed with AWS SNS email subscriptions that alert you to any significant changes or issues.
- Lambda Auto-Remediation: Implement a Python Lambda function to automatically stop EC2 instances when critical alarms are triggered, minimizing downtime and reducing costs.
- Visualization Dashboard: Utilize Terraform to build a CloudWatch Dashboard that provides a comprehensive view of your cloud environment's health and performance.

---

## 📅 Project Timeline

Embark on a five-day journey to transform your cloud infrastructure:

- Day 1: Kickstart your project with Terraform setup for EC2, IAM roles, VPC, and security groups.
- Day 2: Enhance your monitoring capabilities by installing and configuring the CloudWatch Agent on EC2.
- Day 3: Establish a robust alerting system with CloudWatch alarms and SNS email notifications.
- Day 4: Automate your response to critical events by deploying a Lambda function for auto-stopping EC2 instances.
- Day 5: Conclude your project by building a CloudWatch Dashboard to visualize and analyze key metrics.
